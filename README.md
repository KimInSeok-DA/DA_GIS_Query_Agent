# 서울 지하철 접근성 GIS 질의 에이전트

> 작업 중(2026-10-14 시작). 평가 결과가 나오면 첫 표에 정답률을 적습니다.

서울 법정동별 지하철 접근성 데이터에 자연어로 질문하면, LLM이 읽기 전용 도구(SQL·동 찾기)를 골라 실행하고 그 결과로만 답하는 작은 에이전트입니다. 질문 세트의 정답을 코드로 따로 계산해 에이전트 답을 자동 채점합니다.
