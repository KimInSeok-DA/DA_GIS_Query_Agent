# 1015_01 데이터: 지하철 GIS 저장소 공개 CSV 사본

- 상태: 확정 (2026-10-14 사본, 2026-10-15 대조)

## 배경

에이전트가 조회할 데이터가 필요하다. 이 프로젝트의 목적은 데이터를 새로 만드는 것이 아니라 **이미 검증한 GIS 결과 위에 질의 에이전트를 얹는 것**이다.

## 검토한 안

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A | 지하철 GIS 저장소의 공개 CSV 2개를 `data/`에 복사 | 저장소 하나만 받으면 바로 실행. 원본이 바뀌어도 평가 결과가 흔들리지 않음 | 원본과 사본이 어긋날 수 있음(해시로 대조) |
| B | 실행할 때 GitHub에서 내려받기 | 사본 관리 없음 | 네트워크 필요. 원본이 바뀌면 정답·채점이 조용히 달라짐 |
| C | GeoPackage(폴리곤 포함) 사용 | 공간 질의(포함·교차) 가능 | 의존성 증가(GeoPandas 등). 1차 범위의 질문은 대표점·지표로 충분 |

## 결정

**A안.** 평가는 고정된 데이터 위에서 해야 1차·2차 정답률을 비교할 수 있다.
