# 1015_02 Python 버전: 3.14

- 상태: 확정 (사용자 결정, 2026-10-15)

## 배경

10-14 설정 때 `.python-version`을 3.12로 적었다. 사용자가 "왜 3.12인가, 최신을 안 쓰는 이유는?"이라고 물어 확인해 보니 **근거 없이 적은 값**이었다(AI의 습관적 선택).

## 확인한 사실

| 항목 | 결과 |
|---|---|
| 이 PC에 설치된 Python | 3.14.5만 있음. 3.12는 없음(`py -3.12` 실패) |
| 3.14에서 필요한 패키지 설치 | `uv pip install --dry-run`으로 pandas·duckdb·openai·streamlit·pytest 등 52개 모두 해결 |
| 3.14 출시 | 2025-10. 1년 지나 주요 패키지가 바이너리 휠을 냄 |
| 같은 작성자의 다른 저장소 | 빌라 시세 저장소 3.14 |

## 검토한 안

| 안 | 장점 | 단점 |
|---|---|---|
| 3.12 | 더 오래 검증된 버전 | 따로 설치해야 함. 고를 근거가 없음 |
| **3.14** | 설치되어 있음. 필요한 패키지 모두 지원. 다른 저장소와 같음 | — |
| 3.15 | 최신 | 정식 출시 전 |

## 결정

**3.14.** "필요한 패키지가 모두 지원하는 최신 안정 버전"이 기준이다. 예전에 최신 버전을 피했던 이유(휠이 없어 설치 실패)는 지금 해당하지 않는다.

## 결과

`.venv`(Python 3.14.5), `requirements.txt` — 설치한 버전으로 고정: pandas 3.0.6, duckdb 1.5.6, openai 3.31.0, streamlit 1.66.0, python-dotenv 1.2.4, pytest 9.1.1

## 바꾸는 조건

배포 환경(예: Streamlit Community Cloud)이 3.14를 지원하지 않으면 그 환경이 지원하는 가장 높은 버전으로 내린다.
