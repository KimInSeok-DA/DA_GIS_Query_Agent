**gpt-6-luna.** 이 과제는 SQL 한두 개로 답이 나오는 단순한 조회라 경량 모델로 충분한지부터 재는 것이 맞다. 1차 채점 추정 비용 약 $0.03(문항당 요청 2.5회, 입력 5천·출력 1.2천 토큰 가정).

## 보류: gpt-6.1-sol 비교

- 비교 자체는 가능하고 비용도 크지 않다(추정 약 $0.6, 3배 빗나가도 약 $2)
- 그러나 메인 작업(1차 채점 → 오답 분석 → 개선 → 2차 채점, 화면, README)이 아니다 → 메인 작업이 끝난 뒤 **실제 luna 토큰 사용량**으로 비용을 다시 계산해 결정한다
- 하게 되면 의미: luna 오답이 모델 능력 문제인지, 프롬프트·도구 설명 문제인지 가르는 근거
