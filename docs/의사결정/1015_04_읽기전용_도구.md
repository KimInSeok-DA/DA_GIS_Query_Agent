# 1015_04 읽기 전용 도구: run_sql·find_dong

- 상태: 확정 (2026-10-15)
- 코드: `src/tools.py`, 테스트: `tests/test_tools.py`(23개 통과)

## 배경

LLM이 데이터를 직접 보지 않고 **도구를 불러 조회한 결과로만** 답하게 한다. 도구는 읽기 전용이어야 하고(작업 지시), LLM이 만든 SQL이 데이터를 바꾸거나 파일·네트워크에 접근하면 안 된다.

## 도구 구성

| 도구 | 입력 | 출력 | 왜 필요한가 |
|---|---|---|---|
| `run_sql` | SELECT 문 하나 | `columns`·`rows`·`row_count`·`truncated` 또는 `error` | 집계·순위·필터 등 대부분의 질문을 하나의 도구로 처리 |
| `find_dong` | 동 이름(일부) | 후보 목록(`bjd_cd`·구·동·전체 이름), `note` | 동 이름은 SQL로 바로 찾으면 틀리기 쉽다: 같은 이름이 여러 구에 있고, 사용자는 행정동(역삼1동)으로 말하기도 한다 |

`nearest_stations`(대표점에서 가까운 역 N개)는 1차 범위에서 뺐다. `emd.near_station`·`near_dist_m`에 가장 가까운 역이 이미 있고, N개 질문은 1차 채점 결과를 보고 필요하면 추가한다.

## 데이터에서 확인한 사실

| 항목 | 결과 |
|---|---|
| 같은 이름의 법정동 | 2개: 신사동(은평구·강남구), 신정동(마포구·양천구). 로드맵에서 예로 든 관악구 신사동은 **행정동**이라 이 데이터에 없음 |
| 숫자가 들어간 법정동 이름 | 138개(종로1가, 신문로2가 등) → "숫자 지우기"를 무조건 하면 안 됨. `○○N동` 꼴이 바로 안 찾힐 때만 `○○동`으로 다시 찾는다 |
| 같은 이름의 역 | 신촌 2개(2호선 신촌, 경의중앙선 신촌역) |
| 서울 밖 역 | 82개(`in_seoul = 0`) — 동별 지표 계산에는 서울 밖 역도 쓰였으므로 표에 남긴다 |

## 안전장치 (run_sql)

| 장치 | 방법 | 대안과 고르지 않은 이유 |
|---|---|---|
| SELECT만 | DuckDB 파서(`extract_statements`)로 문장 수 1개·종류 SELECT 확인 | 금지 단어 목록(정규식): 주석·대소문자·문자열 안의 단어로 뚫리거나 오탐이 생김 |
| 파일·네트워크 차단 | 표를 올린 뒤 `enable_external_access = false`, `lock_configuration = true` | SELECT 안에서도 `read_csv('...')`로 파일을 읽을 수 있어 문장 종류 검사만으로는 부족 |
| 행 수 상한 200 | `SELECT * FROM (질의) LIMIT 201`로 감싸 잘렸는지(`truncated`) 표시 | 상한 없이 반환: 토큰 비용이 커짐 |
| 시간 상한 5초 | 타이머가 `interrupt()` 호출 | DuckDB에 문장 단위 timeout 설정이 없음 |
| 오류는 메시지로 | 예외 대신 `{"error": ...}` 반환. 감싼 쿼리가 보이는 위치 표시는 뺀다 | LLM이 오류를 보고 SQL을 고쳐 다시 시도할 수 있게 |

**DB 선택: DuckDB(메모리).** SQLite보다 pandas 표를 바로 올리기 쉽고, 파서 API와 외부 접근 차단 설정이 있다.

## 테스트로 확인한 것

- 막히는 것: DROP·DELETE·INSERT·UPDATE·CREATE·SET·COPY·ATTACH·INSTALL, 두 문장(`SELECT 1; DROP ...`), `read_csv`로 파일 읽기, 5초 넘는 쿼리 — 시도 후에도 표 467행 그대로
- 되는 것: WITH 절, ORDER BY 유지, 코드 열 문자열 유지, 200행 상한
- find_dong: 신사동 → 2개 모두, "양천구 신정동" → 1개, 역삼1동 → 역삼동(안내 문구), 없는 동 → "데이터에 해당 동이 없습니다", 후보 20개 상한

## 바꾸는 조건

1차 채점에서 "가장 가까운 역 N개"·"좌표 주변" 질문이 자주 틀리면 `nearest_stations`를 추가한다.
