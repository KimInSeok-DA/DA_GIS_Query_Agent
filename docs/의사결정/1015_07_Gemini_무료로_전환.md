# 1015_07 제공사 전환: OpenAI → Gemini 무료 등급

- 상태: 확정 (사용자 결정, 2026-10-15)
- 이전 결정: [1015_06 모델 선택](1015_06_모델_선택.md)(gpt-6-luna) → 실행하지 못하고 대체됨

## 배경

gpt-6-luna로 1차 채점을 시작하자 첫 요청에서 `429 credit_balance_exhausted`(API 크레딧 없음)가 났다. 사용자는 Claude·Gemini 계정이 있고 OpenAI는 유료 계정이 아니다.

## 확인한 사실 (2026-10-15)

| 제공사 | 무료 API | 근거 |
|---|---|---|
| OpenAI | 없음. ChatGPT·Codex 구독과 API 크레딧은 별개 | 실제 429 응답 |
| Claude | 없음. claude.ai 구독에 API 사용량 미포함 | — |
| Gemini | 있음. Flash 계열 무료, 단 **입력이 제품 개선에 사용됨** | ai.google.dev/gemini-api/docs/pricing |

**gemini-3.8-flash**: 정식(Stable), function calling 지원, 생각(thinking) 수준 low·medium·high. 유료 등급이면 100만 토큰당 입력 $0.75 · 출력 $3.75(2026-12-31까지, 출력에 생각 토큰 포함).

무료 등급 호출 한도: 문서에는 숫자가 없고 AI Studio에서만 보인다. 실제 429 응답으로 **모델별 분당 5회** 확인(`GenerateRequestsPerMinutePerProjectPerModel-FreeTier`, quotaValue 5). **일일 한도는 모델별 20회**(`GenerateRequestsPerDayPerProjectPerModel-FreeTier`, quotaValue 20, 실제 429 응답). 개선용 28문항 1회에 요청 약 60～70회가 필요해 gemini-3.8-flash 무료로는 하루에 한 번도 못 돈다 → 모델 재선택(아래)

## 검토한 안

| 안 | 장점 | 단점 |
|---|---|---|
| A OpenAI $5 충전 | 코드 그대로 | 비용 |
| **B Gemini 무료** | 비용 0. 다른 제공사도 다뤄 본 경험 | 루프 수정, 입력이 학습에 쓰임, 호출 한도 |

## 결정

**B.** 보내는 내용은 공개 데이터와 평가 질문뿐이라 학습 사용은 문제되지 않는다(README 한계에 적는다).

## 바꾼 것

| 항목 | 내용 |
|---|---|
| API 방식 | Responses API → **Chat Completions**. Gemini의 OpenAI 호환 계층이 공식 문서에서 function calling을 지원한다고 밝힌 것이 이쪽(Responses API는 문서에 없음). 같은 코드로 OpenAI도 부를 수 있다 |
| 클라이언트 | OpenAI 라이브러리 + `base_url`(Gemini 호환 주소). `--provider gemini/openai` |
| 호출 간격 | 무료 등급 분당 5회 → 요청 사이 12.5초, 429(분당)면 안내된 시간만큼 기다렸다 재시도, 일일 한도면 그때까지 결과를 저장하고 멈춤 |
| 토큰 집계 | Gemini 호환 응답은 `completion_tokens`에 생각 토큰을 넣지 않고 `total_tokens`에만 넣는다(예: 입력 15·출력 89·합계 1,382). 출력 = 합계 − 입력으로 계산하고 생각 토큰을 따로 기록 |
| 비용 | 실제 비용 0. 보고서에 "유료 등급 환산 비용"을 함께 적는다 |
| 되묻기 이어가기 | `run(..., history=)` — 이전 대화를 넘길 수 있게 함(화면에서 되묻기 후 답할 때) |

## 모델 재선택: gemini-3.5-flash-lite

AI Studio 한도 화면(사용자 캡처, 2026-10-15)의 무료 등급 텍스트 모델:

| 모델 | 분당 | 하루 | 비고 |
|---|---|---|---|
| Gemini 3.8 Flash | 5 | 20 | 오늘 23/20 소진 |
| Gemini 3.7·3.6·3·2.5 Flash | 5 | 20 | 한 번 평가도 못 돎 |
| **Gemini 3.5 Flash Lite** | 15 | 500 | 선택 |
| Gemini 3.1 Flash Lite | 15 | 500 | 한 세대 전 |
| Gemma 4 26B·31B | 30 | 14,400 | 분당 토큰 16K, function calling 호환 계층 지원 미확인 |

프로젝트 전체 예상 요청 약 250회(개선용 28문항 × 여러 번 + 홀드아웃 42문항)가 하루 안에 들어가는 모델 중 가장 최신인 **gemini-3.5-flash-lite**를 쓴다. 유료 환산 가격: 100만 토큰당 입력 $0.30 · 출력 $2.50(출력에 생각 토큰 포함). 호출 간격 4.5초(분당 15회).

하루 한도 초기화 시각: **태평양 시간 자정**(ai.google.dev/gemini-api/docs/rate-limits, "Requests per day (RPD) quotas reset at midnight Pacific time", 2026-10-15 확인). 한국 시간으로는 서머타임 기간 16:00, 11월 초 이후 17:00. 그래서 한국 날짜 하루 안에서도 16:00 전후로 한도가 두 번 생긴다.

경량(Lite) 모델이라 정답률이 낮게 나올 수 있다. 오답 원인이 모델 능력으로 보이면 상위 모델 비교(향후 보완)에서 다룬다.

## 바꾸는 조건

일일 한도 때문에 평가를 하루에 끝낼 수 없거나, 호환 계층 오류가 반복되면 OpenAI 충전(A)으로 돌아간다(코드는 `--provider openai`로 그대로 쓸 수 있다).
