# 외부 질문 만들기 지시문 (holdout_ai)

다른 AI 에이전트에게 평가 질문을 받을 때 쓴 지시문이다. 아래 "지시문" 부분만 그대로 붙여 넣는다.

## 쓰는 방법

1. 이 저장소와 상관없는 **빈 폴더**를 만들어 그 폴더만 연다(이 저장소를 열면 열 이름·도구 설명·기존 문항을 보게 된다)
2. 가능하면 답하는 모델(Gemini)과 다른 계열의 모델을 고른다
3. 아래 지시문을 붙여 넣고, 나온 질문을 그대로 받는다(고치지 않는다)
4. 정답은 이 저장소에서 코드로 계산한다. 정답을 정할 수 없는 질문은 빼되, 뺀 개수와 이유를 기록한다

## 실제로 받은 방법 (2026-10-16)

- 서비스: ChatGPT 무료(Chat 모드), 새 대화. 모델 이름은 화면에 나오지 않아 기록하지 못했다. 파일은 올리지 않았다
- 1차: 아래 지시문을 붙여 넣어 30개를 받음. 말투가 깔끔하고 오타·짧은 말이 거의 없었다(1～3번은 지시문의 예시 동 이름을 그대로 씀)
- 2차: 같은 대화에서 아래 한 줄을 더 보내 다시 30개를 받음. **이 30개를 `holdout_ai`(A01～A30)로 고치지 않고 쓴다.** 1차 세트는 쓰지 않는다

## 지시문

너는 지하철 접근성 데이터를 조회해 주는 챗봇을 시험할 **질문을 쓰는 사람**이다. 챗봇이 실제 사용자에게 어떤 질문을 받을지 상상해서 질문만 써 줘.

### 지켜 줄 것

- **이 대화에 쓴 내용만 보고 써라.** 파일을 읽거나, 폴더를 뒤지거나, 웹을 검색하거나, GitHub 저장소를 찾아보지 마라. 코드도 쓰지 마라
- **정답은 쓰지 마라.** 질문만 쓴다. 정답은 따로 계산한다
- 데이터가 실제로 어떻게 생겼는지(열 이름, 표 구조)는 몰라도 된다. 모르는 채로 쓰는 것이 목적이다

### 챗봇이 가진 데이터 (평범한 설명)

- 서울의 법정동(예: 역삼동, 청담동, 명동2가) 약 470개와 지하철역 약 390개에 대한 자료다
- 동마다: 그 동에서 가장 가까운 지하철역과 그 역까지의 거리(동의 대표 지점에서 잰 직선거리), 동 경계 안에 있는 역의 수, 동 면적 중 역 반경 500m 안에 드는 비율, 동이 속한 구
- 역마다: 역 이름, 노선, 운영기관, 위치(좌표)
- 좌표가 있어서 두 지점 사이 직선거리는 계산할 수 있다
- 2026년 기준 공개 자료로 만든 것이다

### 써 줄 질문

- **30개**, 한 줄에 하나씩
- 실제 사람이 챗봇 입력창에 칠 법한 말투로. 반말·존댓말·짧은 말·오타·띄어쓰기 틀림이 섞여도 좋다
- 여러 사람을 상상해라: 이사할 동네를 고르는 사람, 자취방 찾는 대학생, 부동산 일 하는 사람, 기사 쓰는 기자, 서울을 잘 모르는 사람 등
- 이런 것을 골고루 섞어라
  - 한 동이나 한 역에 대한 단순한 질문
  - 순위·비교·평균처럼 여러 동을 봐야 하는 질문
  - 두세 단계를 거쳐야 답할 수 있는 질문
  - 위 데이터로는 **답할 수 없을 것 같은** 질문(사람들이 흔히 궁금해하지만 위 설명에 없는 것)
  - 무엇을 묻는지 **애매한** 질문(어느 동인지, 무엇을 기준으로 하는지 분명하지 않은 것)
  - 틀린 전제를 깔고 묻는 질문
- 각 질문은 혼자서 뜻이 통해야 한다(앞 질문에 이어지는 질문은 쓰지 마라)
- 비슷한 질문을 반복하지 마라

### 출력 형식

번호와 질문만 쓴다. 설명·분류·정답은 쓰지 않는다.

```
1. 질문
2. 질문
...
30. 질문
```
